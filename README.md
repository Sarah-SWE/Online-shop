# Online Shop

## Overview

A simple online shop web application built with PHP. It lets users browse products in a shop page, add items to a shopping cart, and manage the products with add, edit, and delete operations.

## Assignment

The task was to build an online shop using PHP. The application had to include:

- A shop page that displays the available products
- A products management page to add, edit, and delete products
- A shopping cart where items can be added and removed
- Form validation for user input
- A database connection for storing products and cart data

The goal of the assignment was to practice server-side programming with PHP, including working with forms, connecting to a database, and performing CRUD (create, read, update, delete) operations.

## Tech Stack

- PHP
- MySQL
- HTML5
- CSS3

## Getting Started

### Prerequisites

- A local PHP server environment such as [XAMPP](https://www.apachefriends.org/)

### Installation

Clone the repository into your server's web directory (for XAMPP, the `htdocs` folder):

```bash
git clone https://github.com/Sarah-SWE/Online-shop.git
```

1. Start **Apache** and **MySQL** from the XAMPP control panel.
2. Create a database and import the tables the project uses.
3. Update the database settings in `config.php` to match your local setup.
4. Open `http://localhost/Online-shop/index.php` in your browser.
